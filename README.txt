# Ayla Transport Website

موقع تعريفي جاهز كبداية لـ Ayla Transport.

## الملفات
- index.html
- style.css
- script.js

## التشغيل
افتح `index.html` مباشرة في المتصفح لمعاينة الموقع.

## قبل النشر
1. استبدل البريد المؤقت `contact@aylatransport.com` بالبريد الرسمي إذا أردت.
2. بعد نشر التطبيق على Google Play، ضع رابط المتجر في زر التحميل.
3. يمكن ربط الموقع لاحقًا بنطاق خاص مثل نطاق Ayla المتاح.
